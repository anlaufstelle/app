{% comment %} components/_action_button.html — einzelne Kontextaktion (Konzept #1801 §6.2/§6.4, Refs #1813 T4). Mitgliedschaft und Reihenfolge der Aktionen stehen in der jeweiligen ``core//partials/_actions.html`` — hier verzweigt NUR die Pixelform. Parameter: - variant: "desktop" | "mobile". - position: "primary" | "overflow" (Default "primary"). Primär sitzt direkt in der Aktionsleiste, Overflow in der ⋮-Dropdown-Zeile — folgenschwere Aktionen (Löschen, Fall abschließen, Löschung beantragen) sind NIE primary. - base_url: Ziel-Pfad (Pflicht). - query_param_name / query_param_value: optionaler ``?name=value``-Anhang (z. B. ``?client=``); ohne Wert bleibt die URL unverändert — R8 verlangt genau das für ein anonymes Ereignis. - label: sichtbares/aria-Label (immer über ``{% trans … as … %}`` befüllen). - label_short: optionales KURZLABEL, das mobil SICHTBAR neben dem Icon steht (Refs #1859). Ohne diesen Parameter bleibt die Mobilform icon-only. **WCAG 2.5.3 (Label in Name):** ``label_short`` MUSS — in JEDER Sprache, Groß-/Kleinschreibung egal — ein Teilstring von ``label`` sein, denn ``aria-label`` traegt weiterhin den vollen Text. „Kontakt" ⊂ „Kontakt dokumentieren" und „Contact" ⊂ „Document contact" halten das ein; ein Kurzlabel, das den Langtext NICHT enthaelt, macht den Knopf per Sprachsteuerung unansprechbar. Der Guard dazu: ``tests/test_detail_actions_parity.py::TestMobileActionPixelForm`` (inkl. EN-Gegenprobe). - testid: data-testid; testid_mobile überschreibt ihn nur für variant="mobile" (Bestandscode hat eigene "mobile-"-Präfixe für einzelne Buttons). - icon_path: SVG-"d"-Pfad als reiner String (kein Markup, kein ``|safe`` nötig). Ohne icon_path bleibt die Aktion ohne Icon. - icon_stroke_width: optional, Default "2" (die "+"-Icons nutzen "2.5"). - highlight: bool — hebt GENAU eine primäre Aktion mit ``btn-primary`` hervor (die häufigste, §6.2 Rangregel). Wird in "overflow" ignoriert. - extra_class: zusätzliche Klassen (z. B. "text-red-600" für Löschen). Mobil verliert eine PRIMARY-Aktion höchstens ihr volles Label (Icon + aria-label bleiben, mit ``label_short`` zusätzlich ein sichtbarer Kurztext) — nie ihren Eintrag (§6.4 Paritätsregel). Overflow-Zeilen zeigen auf beiden Varianten Icon + Label (identisch zur bisherigen Mobil-Menü-Optik).
