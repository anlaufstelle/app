{% load i18n %} {% comment %} Interaktives Feld-Board (M0 P6/P7, Refs #1056) — DAS zentrale HTMX-Swap-Ziel `#field-board`. Jede Board-Mutation (Feld zuordnen/entfernen, Gruppe anlegen/ umbenennen/löschen, Drag-and-Drop-Sortierung) ersetzt diesen Container per outerHTML. Sortierung ist im View/Service vorbereitet (Gruppen nach (sort_order, name), Felder je Gruppe nach sort_order, „Ohne Gruppe" als fixer Block zuletzt) — NICHT hier sortieren. Drag-and-Drop (P7, config-sortable.js): * `data-sortable="groups"` umschließt die verschiebbaren Gruppen-Karten (jede mit `data-group-id` + `.group-drag-handle`); Reorder-Ziel-URL in `data-reorder-url`. * je Gruppe/„Ohne Gruppe" eine `data-sortable="fields"`-Liste (`data-group-id`, Felder-Reorder-URL in `data-reorder-url`, Move-URL in `data-move-url`); jede Feldzeile trägt `data-dtf-id` + `.field-drag-handle`. Distinkte Handle-Klassen für Gruppen vs. Felder verhindern die Handle-Kollision verschachtelter Sortables. Das Sortable wird NICHT im Template initialisiert (kein Inline-JS). Kontext: doc_type, groups (mit vorsortierten .fields), ungrouped_fields, add_form (DocumentTypeFieldAddForm), group_form (FieldGroupForm). {% endcomment %}
